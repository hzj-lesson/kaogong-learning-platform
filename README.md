# 考公学习平台 · 2028 国考备考版

一个为公务员考试备考设计的**单页应用**（纯前端 HTML，无需后端、无需安装）。

## 在线使用

直接用浏览器打开 `考公学习平台.html` 即可，双击文件或拖进浏览器都行。

> ⚠️ **重要**：所有学习数据（任务进度、打卡、笔记、错题本）**只存在当前浏览器的本地存储**中，不联网同步。换设备、换浏览器、清理缓存都会丢失，**请定期用页面内的「⬇ 导出备份」功能导出 JSON 备份**。

## 核心功能

| 模块 | 说明 |
|------|------|
| 📋 仪表盘 | 总进度环、倒计时、待办清单、今日打卡、26 周打卡热力图、待攻克薄弱点 |
| 🗂️ 路线任务 | S0~S3 四个阶段共 **32 个任务**，覆盖 2026.09 – 2027.11 完整备考周期 |
| 🍅 番茄钟 | 专注 25' / 短休 5' / 长休 15'，每 4 轮长休息，用时间戳校准不丢秒 |
| 📝 笔记日志 | 学习笔记、每日学习日志、错题本（带错因标签与随机复习） |
| 🔗 资源 | 刷题、时政、免费课程、信息交流四类备考资源导航 |

每个任务都配有**知识点详解**：名词解释、核心要点、常见陷阱、自测题（含答案）、深入学习清单、掌握度标记（未学 / 学习中 / 能讲 / 能写）。

## 备考路线

| 阶段 | 时间 | 主题 |
|------|------|------|
| S0 | 2026.09 – 2026.11 | 基础入门：摸清五大模块，找到节奏 |
| S1 | 2026.12 – 2027.04 | 模块强化：专项突破，正确率上 80% |
| S2 | 2027.05 – 2027.08 | 套卷实战：真题为王，稳住正确率 |
| S3 | 2027.09 – 2027.11 | 考前冲刺与面试：临门一脚 |

## 使用技巧

- **快捷键**：`1`~`5` 切换标签页，`Esc` 关闭弹窗
- **掌握度**：任务可标记「未学 → 学习中 → 能讲 → 能写」，帮助识别真正的薄弱点
- **错题本**：自测答不上来时点「记入错题本」，选错因标签，之后可随机复习
- **快照恢复**：重置 / 导入前会自动存快照，误操作可从「🛟 快照恢复」找回
- **深色模式**：右上角可切换，偏好会被记住
